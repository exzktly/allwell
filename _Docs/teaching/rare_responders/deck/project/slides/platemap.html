The walk through the assay starts at the largest scale, the plate, as the map at top right shows. Here the experiment is laid out: every well gets one condition, either the control (DCs with no molecule) or one test molecule. Each plate holds six donors, because T-cell responses differ from person to person. For each donor there is a control column, DCs with no molecule, and one column each for test molecules A, B and C. Each donor has a block of four columns by four rows: each condition fills four wells down its column, and those four wells are the replicates that the test at the end compares, always within a donor: for example donor 1’s four molecule-A wells against donor 1’s four control wells. The later slides draw only three of each condition’s wells, to keep the pictures readable. Every molecule is compared with the controls in the same way. The ringed well is a molecule-A well; the next slides zoom into it, first to the well and then to one of its nanowells.
