Table Builder

Give each dimension a role — the table renders itself.

Replaces the build-then-generate grid of dropdowns. Your data varies across four dimensions — Well, Channel, Timepoint, FOV. Drag each one into a role: stack it down the Rows, spread it across the Columns, Hold it at one value, or Merge channels into a single composite. Drop two into a zone to nest them. The image grid re-lays-out live — no separate Build step.
