Table Builder

Set a root, nest channels under it — the table renders itself.

Each axis — Rows and Columns — starts with a root: a Well (from the plate map), a Timepoint, or an FOV. Drag channels onto a root and they nest under it, indented. Each nested channel carries its own render options — raw / corrected · mask · outline · ≥ threshold and colour — set with the ⚙ on the chip. Any dimension you don't lay out drops into Fixed, pinned to one value for the whole table — change it there, or drag it back onto an axis to make it vary. Remove a channel with its ×; turn a root's channels into a single blended cell with Overlay. Live — no Build step.
