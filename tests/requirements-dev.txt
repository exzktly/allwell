# Test/CI dependencies.
#
# Two rules govern this file:
#
# 1. NO heavy ML stack. tensorflow/torch/stardist/cellpose are deliberately
#    absent — the segmentation/pipeline tests mock them or degrade gracefully.
#    Consequence: the `importorskip("stardist")` / `importorskip("tensorflow")`
#    tests SKIP in CI. A green CI run has not exercised them.
#
# 2. PIN to the versions the app actually ships against (requirements.txt
#    and requirements-remote.txt). These were lower bounds (`numpy>=1.20`,
#    `pandas>=1.3`, …), which pip resolves to the newest release — so CI was
#    testing against numpy 2.x / pandas 3.x while the app runs numpy 1.24 /
#    pandas 2.2. Two major versions of drift, on the exact libraries the
#    data-loading and stats layers sit on. Any failure that gap produced was a
#    CI artifact; any bug it masked was real and unseen.
#
# numpy's band mirrors the mamba constraint in requirements.txt
# (`"numpy>=1.24,<1.25"`) and is the binding pin — TF 2.13 and StarDist hold it
# there. scipy / scikit-image / matplotlib are capped only so pip cannot resolve
# a numpy-2-only wheel above it. Resolution and a full fast-lane run were
# verified on Python 3.11 (CI's version) before this landed.
#
# See .github/workflows/ci.yml and scripts/test.sh.

# ── Test harness ─────────────────────────────────────────────────────────────
pytest>=7.0
pytest-qt>=4.2
pytest-mock>=3.10
pytest-timeout>=2.1
pytest-cov>=4.0
# The fast lane runs one worker per CPU (scripts/test.sh, --dist loadfile); without it the lane
# runs serially, which took it past CI's 15-minute job cap.
pytest-xdist==3.8.0
# Differential coverage: which lines THIS diff adds that no test executes.
# A percentage over ~500 files is a number to game; the diff is the question
# a reviewer actually has.
diff-cover>=9.0

# ── Runtime stack — pinned to match the shipped app ──────────────────────────
PySide6==6.7.3
numpy>=1.24,<1.25
pandas==2.2.3
matplotlib>=3.5,<3.10
pillow>=9.0

# Imported at module-load time by the pure-pipeline modules (process_microscopy
# imports tifffile for its codec side effects; flatfield/QC use scipy + skimage).
tifffile==2023.9.26
scipy>=1.9,<1.14
scikit-image>=0.20,<0.25
imageio>=2.30

# The Parquet engine behind the per-well frame cache. Present here for two
# reasons that are not the same. It is what the cache runs on, so without it
# `tests/test_parquet_cache.py`'s module-level `importorskip` skips the WHOLE
# file in CI — including the two guards in it that need no engine at all: the
# one-door AST check, and the check that no verdict column reaches the cache.
# A guard that silently does not run is worse than no guard, because it is
# reported as one. And it is a GUI-side dependency (`requirements.txt`),
# deliberately absent from `requirements-remote.txt` — the pipeline writes
# these CSVs and never reads them back — so nothing else here pulls it in.
#
# Pinned like the rest of this file, and to the same version the app declares.
pyarrow==22.0.0

# Reading the ND2 fixture's own bytes back. `tests/_nd2_fixture.py` writes real
# ND2 files and the round-trip through this package is what makes them evidence
# about the format rather than about our own assumptions — so the ND2 tests
# `importorskip` it, and without it installed they skip rather than lie.
#
# Pinned to the same version the app declares, like the rest of this file.
nd2==0.9.0
