How the 95 % interval is found

1. Start at the top of the hill, the best δ
2. Draw a line 1.92 below the top
3. The interval is every δ whose log L is above that line
Here: δ from 0.53 to 1.27
As odds ratios, exp(δ): 1.7 to 3.6

Why 1.92
It is the test of slide 18 run backwards
A value of δ is kept if testing it gives D below 3.84
3.84 = 1.96², and D = 2 × the drop in log L
So the allowed drop is 3.84 ÷ 2 = 1.92

The odds ratio comes with a 95 percent interval, 1.7 to 3.6 for A. It is read off the same hill as slide 15. Start at the top, the best estimate of δ, 0.89. Draw a horizontal line 1.92 units of log-likelihood below the top. Every value of δ whose log-likelihood is above that line belongs to the interval; here that is from 0.53 to 1.27. Taking e to those powers gives odds ratios from 1.7 to 3.6. Why 1.92? Because the interval is the test of slide 18 run backwards: a candidate value of δ is kept if a test of that value would not reject it at the 5 percent level, two-sided. That test rejects when D exceeds 3.84, the square of 1.96, and D is twice the drop in log-likelihood, so the allowed drop is 1.92. The interval is not symmetric because the hill is steeper on one side than the other. An interval that excludes zero, an odds ratio of 1, goes with a two-sided p below 0.05; molecule C’s interval, 0.96 to 2.2, includes 1.
