# Review remediation — the directory-listing branch

Fourteen findings from an adversarial review of
`claude/windows-pipeline-dir-slowness-n4s8z3`, worked one row at a time. Each
row moves to `done` in the same commit as its fix, with the evidence named. A
row that turns out not to be a defect goes to `declined` with the reason written
here and at the site, never dropped — a dropped row and a forgotten one look
identical a week later.

This file is deleted by the commit that closes its last row. If you are reading
it on `main`, something went wrong.
