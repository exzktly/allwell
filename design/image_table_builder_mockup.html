Table Builder

Drag chips onto the map — the table renders itself.

Every chip in the tray is a thing you can drag onto the map. Layer chips are channels rendered a particular way — DAPI corrected, GFP raw, a cell mask, an outline — each with its own colour/LUT, edited right on the chip. Facet chips (Wells, from the plate map · Timepoints · FOVs) arrange copies of those layers. Drop chips into Rows, Columns, or Hold; the layers sharing an axis get a Facet ↔ Overlay switch to composite them into one cell. Live — no Build step.

Interactive mockup — synthetic thumbnails. This is the control surface only; underneath, the shelf writes the same row_dims / col_dims / group_size / active_wells state the current layout math and render pipeline already consume — the plate map is the existing sidebar WellPlateSelector, and each Layer chip is a channel + a variant that maps to today's per-row Source (raw/corrected), Boundaries, and Binary (mask / ≥thr) renderers, with its own LUT. So image_table_generate, the compose/LUT/export layers, and view-state persistence are reused. Full write-up: _Docs/Markdowns/IMAGE_TABLE_BUILDER_DESIGN.md.
