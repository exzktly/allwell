# Rare responders view: usability and correctness tracker

a UX review and a statistics and code review of the view as merged in #1324–#1331. The user's report: the view is
"indecipherable". This file is deleted by the pull request that closes its last row.

Each row is a finding, checked against the tree before it was worked. Its state is `open`, `done` (with the test
that pins it, seen failing without the fix) or `declined` (with the reason, also written at the site).

Counts are taken from the rows below, not typed: run `grep -c '| done |' …`, `grep -c '| open |' …`,
