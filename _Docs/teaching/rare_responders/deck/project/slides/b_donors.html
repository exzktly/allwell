Reading across donors: say in how many donors a molecule was detected, and give each donor’s odds ratio with its interval

The worked example used one donor. A real plate holds several. The comparison is always made within a donor: each molecule’s wells against that donor’s own control wells, because T-cell responses differ between people and mixing donors would add their differences to the scatter. The correction for testing several molecules covers every molecule compared in one analysis, so analysing one donor at a time gives each molecule one verdict per donor. When one donor’s wells are spread over several plates, they are treated as one set: no offset is fitted for the plate, so plate-wide differences such as the day of imaging add to the scatter between wells. There is no term for the donor either, which is why each donor is analysed alone. Donors are not combined into a single p-value. To read across donors, report in how many donors a molecule was detected and give each donor’s odds ratio with its interval. A molecule detected independently in several donors is stronger evidence than any single p-value.
