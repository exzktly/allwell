# Array view UX review — tracker

A UX review of the Nanowells page's Array view (key, footer, Notes, rim focus box) returned eight findings, all to be
fixed in the same pull request as the changes reviewed. One row per finding; a row is `done` only with the test that
pins it. This file is deleted by the pull request that closes its last row.

Counts are derived from the rows below: count the `done`, `open` and `declined` cells, never a typed total.

| # | Finding | Fix | State | Evidence |
|---|---|---|---|---|
| B1 | The no-value nanowells cannot be told apart on the array: every reason draws the same plain grey ring, while the Notes footer says a hatch or dash names why. "Seeded later" also guesses a cause. | Each no-value nanowell writes its reason inside it, where its value would be (Values layer); the key lists one entry per reason; "seeded later (0 at baseline)" becomes "0 cells at baseline" everywhere it is shown. | done | `test_nanowell_page.py::test_a_nanowell_with_cells_and_no_fold_change_says_why_on_the_array` (fails with `('2,0', '3,0') == ('0 at base', 'base occl.')` with the tag removed); `test_nanowell_array_key.py::test_a_nanowell_with_no_value_is_keyed_with_why`; `test_nanowell_array_controls.py::test_a_label_writes_three_significant_figures_and_never_a_missing_value_as_a_number`. Label is "no cells at baseline", not "0 cells…": the Extremes and Distribution footers write a count before it. |
| N1 | The counts line ("19 nanowells in the roster · with a value 13 · measured 17 · out of focus 2") does not add up against the key. | One line in the key's own buckets that sums to the roster: "19 nanowells: 13 with a value · 4 no value · 2 out of focus". | done | `test_nanowell_page.py::test_the_array_footer_is_short_until_notes_is_turned_on` and `test_nanowell_page_views_ui.py` assert `4 nanowells: 3 with a value · 1 occluded`. |
| N2 | The count sits in different places in the key's entries ("no value · 4: …" against "no value: rim out of focus · 2"). | Every entry ends with its count. | done | `test_nanowell_array_key.py::test_a_nanowell_with_no_value_is_keyed_with_why` (every entry `… · N`). |
| N3 | Turning Notes on shrinks the array and moves the grid. | The notes are drawn in a box over the foot of the array; the footer's reserved height does not change with Notes. | done | `test_the_array_footer_is_short_until_notes_is_turned_on` asserts the axes bounds unchanged; fails with `(0.03, 0.26, …) == approx(…)` when Notes reserves footer height. |
| N4 | Notes explains what is not on screen ("Fused: …" with no fused nanowell; "A01 at t_a: ok."). | Each notes line only when it applies to what is drawn; a plain "ok" grid status is never written. | done | Same test asserts the exact notes lines (no fused sentence, no `: ok.`); fails when the fused sentence is always written. |
| N5 | A pause mid-number commits the partial number, invisibly. | A spin box shows typed text not yet committed in italics until it commits or is reverted. | done | `test_spin_boxes_commit_typed_values_once.py::test_typed_text_not_yet_in_force_is_shown_in_italics` (fails with the pending style unhooked). |
| N6 | The Notes switch is hard to find under Layers. | A checkable Notes button on the Array view's band beside Overlays, in step with the Layers entry. (Not drawn in the figure: a click on the figure selects nanowells, and anything drawn there is exported.) | done | `test_the_array_footer_is_short_until_notes_is_turned_on` drives `_nw_notes_btn` and the Layers entry and checks each follows the other. |
| N7 | Addresses are unreadable over the out-of-focus dot hatch; "Nanowell identity — A01 not checked (see Identity)." does not say whether that is a problem. | Labels drawn with a halo of the ground colour; the identity sentence reads "Nanowell addresses: A01 not yet verified — see the Identity view." | done | `test_nanowell_array_controls.py::test_every_label_has_a_halo_of_the_ground_so_it_reads_over_a_hatch` (fails with the halo removed) and `::test_a_label_on_a_metric_fill_has_no_halo` (fails with the halo on every label: on the metric's fill it only roughened them); `test_nanowell_identity_review.py` asserts `Nanowell addresses: A01 not yet verified`. |
