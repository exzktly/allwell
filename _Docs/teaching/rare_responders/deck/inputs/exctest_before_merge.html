Well = one condition: one test molecule, or the control

Nanowell = one DC + a few T cells, imaged and counted on its own

The test, run for each molecule against the same four control wells. Card 1: the wells. The test fits each well’s own count; it never adds the counts up. What differs is how their four replicate wells agree. A’s four wells all sit around 24, so the model finds r close to zero: so chance alone moves the gap very little. B has three wells that look like controls and one at 64, so the model can only explain B by letting wells differ a lot, r about 0.008, and with that much chance variation B’s gap is not convincing. Card 2 walks through the test one step per line: fit with the gap, fit without it, compare the two fits, and read off p; for A p = 0.00008, for B p = 0.18. The odds ratio from the first fit is 2.4 for A and 1.5 for B. The counts are illustrative.
